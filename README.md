# Flute Days — iPhone公開用セット

ガリボルディ Op.132 とともに練習する、フレンチスタイルの練習帳。

## GitHub Pagesで公開する
1. GitHubで新しい **Public** repository（例 `flute-days`）を作成します。
2. このZIPを解凍し、**中身のファイルをすべて** repository の最上位にアップロードします（ZIP自体をアップロードしないでください）。
3. GitHub の repository → **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、**main / (root)** を選択して Save。
4. Pagesに表示された公開URLを iPhoneのSafariで開きます。
5. Safariの共有メニュー → **ホーム画面に追加** →（あれば「Webアプリとして開く」をオン）→ 追加。

## 大切な注意
- Webサイトの画面・プログラムは一般公開されます。個人的な名前やメモを index.html に書き込んで公開しないでください。
- 練習記録は各端末のブラウザ内（localStorage）に保存され、GitHubへ送信されません。**自動同期はありません。** Safariのデータ消去や端末変更で消える場合があるため、サイト内の書き出し機能でこまめにバックアップしてください。
- ホーム画面版とSafari版で保存データが共有されない場合があります。**日常的にはどちらか一方で使用**してください。
- 初回はインターネット接続が必要です。以降はオフラインで開ける場合がありますが、外部Webフォントは接続状況に依存します。
- GitHub Pagesへの公開はまだ行っていません。公開作業はGitHubアカウント側で必要です。
